# RPG HUD와 경험 기반 NPC 행동 개편

## 변경 의도

기존 직업별 생성·행동 보너스를 제거했다. NPC는 고정된 사냥꾼/상인이 아니라,
성격과 처한 상황에 따라 행동을 선택하고 그 결과가 누적되어 편향되는 주민이다.
성향 표시는 행동을 제한하는 클래스가 아니라 학습 가중치를 요약하는 표시다.

## 화면과 조작

- 좌측 상단: 플레이어 레벨, 체력, 경험치, 무기, 공격 대기시간.
- 우측 상단: 미니맵, 현재 마을 이름, 아래에 금화와 재료.
- 좌측 선택 패널: NPC 이름, 현재 성향, 행동, 목표, 체력, 자산, 깨달음, 가장 강한 경험 편향.
- 좌측 하단: 최근 마을 소식 2개. 긴 소식은 줄여 표시하며 원문 사건은 로그에 남는다.
- 하단 중앙: 키보드 단축키 카드. 클릭 버튼이 아니라 키 안내다.
- 개발용 상단 전면 배너와 중복된 목표/설명을 기본 화면에서 제거했다.
- 정상 체력의 비선택·비적대 NPC는 체력바를 숨긴다.
- 마을/공격 범위 원은 기본적으로 숨기고 R로 표시한다.

| 입력 | 현재 기능 |
| --- | --- |
| 좌클릭 | 동적 NPC 관찰. 중립 NPC에 대한 공격 지정은 하지 않음 |
| Ctrl+좌클릭 | NPC를 명시적 공격 대상으로 지정 |
| 우클릭 | 선택과 명시적 공격 지정을 해제 |
| T | 마을의 비적대 주민 3.5타일 안에서 재료 판매 / 재료가 없으면 회복 구매 |
| Y | 같은 조건에서 경험치 구매 |
| G | 가까운 NPC 소지품 습득 |
| F | 기존 안내/영혼 NPC 대화 |
| P | 일시정지 |
| H | 확장 도움말 |
| F8 | 개발 정보 표시/숨기기 |
| F9 | 기존처럼 시드를 보존하고 플레이 상태 초기화, 확인 및 백업 포함 |

적대 NPC는 관찰 여부와 관계없이 기존 자동 방어의 대상이다. 이미 발사된 투사체는
공격 선택을 해제해도 사라지지 않는다. 기본 1280×800을 중심으로 배치했다.
생활 패널은 700×560 이상, 개발 패널은 너비 900 이상에서 표시한다.

## 행동을 통한 편향

1. 신규 주민은 직업 없이 생성된다. 초기 금화 30, 재료 2이며 성격 6축은 독립적으로 다양하게 배정된다.
2. 체력·자산·성격·근처 적·소지품·부상자·마을 위치로 행동의 기본 가중치를 계산한다.
3. 가능한 행동에만 학습 가중치를 더하고 가중 무작위로 선택한다.
4. 사냥/거래/약탈/채집/제작/구호 등의 성공은 해당 행동을 강화한다.
5. 피해는 당시 행동을 약화하고 도주를 강화한다. 완료하지 못하고 시간이 만료된 행동도 소폭 약화한다.
6. 학습치는 -20~40으로 제한하고 시간에 따라 완만하게 감쇠한다(시정수 600 시뮬레이션 초).
   따라서 한번 편향되더라도 다른 경험을 통해 전환할 수 있다.
7. 당장의 목표도 고정되지 않는다. 체력이 55% 미만이면 생존/성장, 금화 40 미만이면 부,
   그 외에는 깨달음을 우선한다.

학습 경험이 적으면 '미분화'로 표시한다. 누적 경험에 따라 사냥·약탈·교역·탐구·생산·협력
성향으로 표시와 의복 색이 바뀐다. 이 표시는 행동 선택이나 거래 자격의 입력이 아니다.
모든 비적대 주민과 재고/금화 조건이 맞으면 거래할 수 있다.
NPC 간 금화 거래는 자산을 이전하며 거래 자체가 금화를 생성하지 않는다.
제작·치료는 재료를 소비하고 채집은 지역 자원량을 소비한다.

## 13가지 행동

| 행동 | 실제 수행 / 결과 |
| --- | --- |
| 사냥 | 실제 몬스터 추적·공격, 처치 보상과 경험 |
| 거래 | 마을에서 주민 사이 재료와 금화 교환 |
| 약탈 | 사망 소지품으로 이동해 재화 습득 |
| PK | 주민 또는 플레이어 공격, 전리품/피해 경험 반영 |
| 탐구 | 야외 목적지에 도착하면 깨달음·경험 획득 |
| 휴식 | 마을 귀환·회복, 회복 완료 경험 반영 |
| 도주 | 낮은 체력에서 빠른 귀환·회복 |
| 채집 | 야외 이동 후 지역 자원을 소비하여 재료 획득 |
| 제작 | 마을에서 재료 2개 소비, 도구 제작 숙련을 경험치 5로 반영 |
| 구호 | 근처 부상자를 찾아 재료 1개로 체력 최대 25 회복 |
| 교류 | 마을의 가까운 주민과 경험 공유, 깨달음과 협력 경험 |
| 마을 방문 | 다른 마을로 실제 이동, 도착하면 거점 변경 및 깨달음 획득 |
| 명상 | 마을에서 시간을 보내 깨달음 1과 경험치 2 획득 |

새 행동은 경로 이동과 경과 시간을 요구한다. 벽 때문에 도착하지 못하면 보상을 주지 않는다.
교류는 가까운 상대, 구호는 살아 있는 부상자와 재료가 필요하다.
제작은 별도 장비 아이템/인벤토리를 만들지 않는 숙련 프로토타입이다.
NPC의 공간 충돌 회피나 완전한 사회 관계망·경비 시스템은 이번 범위가 아니다.

## 거리별 갱신과 기록

근거리 0.1초/중거리 0.5초 갱신은 유지한다. 로딩되지 않은 지역은 15초 단위로 같은
가중치 선택을 사용하고 사냥·채집·탐구·명상·제작·이동·거래를 축약 처리한다.
먼 곳에서 정밀 PK·추적·구호를 재현하지는 않는다. 그 외 선택은 회복으로 축약한다.
먼 NPC의 귀환/거점 이동은 통계 처리이며 전체 물리 시뮬레이션과 동일한 결과를 보장하지 않는다.

- `world_events.csv`: 기존 사건에 tendency, gather, craft, aid, socialize, travel, meditate 등 추가.
- `npc_states.csv`: 5초마다 현재 성향, 행동, 자산, 13개 선택 가중치와 13개 학습치를 기록한다.
- 상태 로그는 v2 세션 헤더 뒤부터 열 수가 증가한다. 분석 시 기존 v1 행과 구분해야 한다.
- 감쇠만으로 표시가 달라지는 경우 별도 사건은 없지만 다음 상태 스냅샷에 반영된다.

## 저장 호환

사회 저장 형식을 `GSE_SOCIETY 2`로 올렸다. v1도 읽으며 기존 시드, 주민, 자산, 성격,
7개 학습치를 보존하고 추가 6개 학습치는 0으로 시작한다. 이전 직업 값은 검증만 하고 폐기한다.
따라서 기존 주민의 직업별 초기 성격은 과거 데이터로 남지만 더 이상 직업별 행동 보너스나
권한은 없다. 완전히 새 분포를 확인하려면 F9를 사용한다.

v1 로드 성공 후 기존 파일을 `world_simulation.dat.before_v2`로 백업한다(이미 있으면 유지).
다음 자동 저장에서 v2로 기록한다. v2 데이터를 이전 실행 파일로 여는 것은 지원하지 않는다.
현재 실행 중인 게임이나 저장 파일을 도구로 직접 수정하지 않았다.

## 수동 확인 목록 — 아직 실행하지 않음

사용자 요청에 따라 빌드·실행 검증은 수행하지 않았다.

1. 기본 해상도에서 상태창·미니맵·재화·알림·NPC 선택창·도움말·대화창의 겹침 확인.
2. 좌클릭은 관찰만, Ctrl+좌클릭은 사거리 내 공격, 우클릭은 지정 해제인지 확인.
3. F8/H/R 표시 전환과 기존 WASD/F/T/Y/G/P/F9 입력 확인.
4. v1 저장 로드 후 백업 존재와 자산 보존, v2 저장 후 재실행 확인.
5. 주민을 관찰하면서 행동 성공 후 경험 편향이 증가하고 의복/성향이 변하는지 확인.
6. 채집 자원 소모, 제작 재료 2개 소모, 구호 재료 1개와 체력 회복, 마을 간 이동 확인.
7. 거래 상대가 기존 상인 외 주민도 가능한지, 자금/재고 부족 시 거래가 거절되는지 확인.
8. 장시간 실행 시 경제 균형, 행동 빈도, PK 빈도, 경로 막힘은 로그로 조정 필요.
