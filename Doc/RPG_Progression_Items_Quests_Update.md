# RPG 플레이 순환 확장

## 목적과 구현 범위

사냥 → 전리품 습득 → 장비 착용/거래 → 의뢰 보상 → 마을 보스 도전의 순환을 추가했다.
기존 NPC 성향 학습, 영혼 NPC 생성, 레벨 100, 청크 스트리밍과 연결한다.
빌드·실행·화면 확인은 사용자 요청에 따라 수행하지 않았다. 아래 밸런스는 코드 기준 초기 설정이다.

## 조작

| 입력 | 동작 |
| --- | --- |
| Tab | 인벤토리 열기/닫기 |
| Q | 퀘스트 열기; 패널 안에서는 닫기 |
| T | 같은 마을의 가까운 비적대 주민(3.5타일 이내)과 상점 열기 |
| 1 / 2 / 3 | 인벤토리 / 상점 / 퀘스트 탭; 상점은 T로 시작한 거래 중에만 가능 |
| W/S 또는 위/아래 | 목록 선택 |
| A/D 또는 좌/우, 휠 | 페이지 이동 |
| E / Enter | 인벤토리에서 착용·해제·사용, 퀘스트에서 보상 수령 |
| B / Enter | 상점에서 선택 아이템 구매 |
| X | 거래 중 인벤토리 탭에서 선택 아이템 1개 판매 |
| M | 거래 중 기존 사냥 재료 판매 |
| Esc | 패널 닫기 |

목록/탭/버튼은 마우스 클릭도 지원한다. 패널 사용 중 세계 시뮬레이션과 보스 시간이 멈춘다.
기존 P 일시정지는 패널을 닫아도 유지된다. 지원 최소 패널 창 크기는 760×600이다.
평상시 좌측 의뢰 추적기는 첫 미수령 의뢰를 표시한다. NPC 상세/도움말/대화와 겹치지 않게 숨긴다.

## 주기적 마을 보스

- 기존 일반 몬스터 24마리 처치 조건을 제거했다.
- 신규 RPG 진행 시작 후 180초에 첫 등장. 처치 후 300초에 다음 등장.
- 5개 마을 중 직전 등장 마을을 제외하고 선택한다.
- 안전 구역을 유지하기 위해 마을 내부가 아닌, 성문 바깥 18~25타일의 연결 도로에 생성한다.
- 보스가 살아 있는 채 300초가 지나면 다음 마을로 교체한다. 플레이어가 보스 18타일 이내에 있으면 30초 연장한다.
- 동시에 한 마리만 유지한다. 먼 미로딩 마을에도 이벤트 위치는 기록하고, 청크가 로딩되면 실체 전투를 진행한다.
- HUD에 마을 이름/권장 Lv 10/거리 또는 다음 등장까지 시간을 표시한다. 기존 BOSS 화면 가장자리 안내도 유지한다.
- NPC가 마지막 공격을 했어도 플레이어가 피해를 주었고 처치 시 30타일 이내이면 공동 처치로 인정한다.
- 보상: 경험치 180, 금화 180, Lv 10 장비 1개 확정 + 기존 영혼석/강화/회복/자석 전리품.
  기존 사냥 공통 보상(금화 4와 재료 1)도 별도로 유지한다.

### 레벨 10 초기 밸런스

보스 체력은 4,500이다. 기존 예고 공격(24, 격노 32), 방사형 탄환(12), 접촉 피해(14)를 유지한다.
플레이어 기본 Lv 10 체력은 235이며, Lv 10 방어구/장신구 착용 시 최대 체력은 315다.
방어력 15 기준 피해 배율은 `100 / (100 + 15×3) ≈ 0.69`이다.
Lv 10 무기/장신구, 강화 0 기준 공격력 64.5, 발사 간격 약 0.32초로 명중이 계속되면 약 22초가 이론적인 처치 시간이다.
실제 회피·이동·잡몹·NPC 지원은 반영하지 않은 계산이다. 강화 +20까지 성장한 기존 캐릭터는 훨씬 빠르게 처치할 수 있다.
실측 후 보스 HP/공격 간격/강화 배율을 조정해야 한다. 레벨에 따라 자동으로 강해지는 보스는 아니다.

## 아이템·장비·경제

- 무기 5종, 방어구 5종, 장신구 5종, 치유 물약, 영혼 자석, 판매용 유물: 총 18종.
- 장비 요구 레벨은 종류별 1/4/7/10/15. 무기 공격력, 방어구 최대 HP/방어력, 장신구 HP/발사 간격/이동 속도 보너스.
- 무기·방어구·장신구 각각 1개 착용. 다른 장비 선택 시 교체, 같은 장비 선택 시 해제.
- 인벤토리 수량은 착용 중인 1개를 포함한다. 마지막 착용 장비는 판매 불가; 여분은 판매 가능.
- 아이템별 999개 상한. 가방이 가득 차면 해당 바닥 아이템은 남는다.
- 최대 HP 장비 착용으로 현재 HP가 회복되지는 않는다. 해제 시 현재 HP를 새 최대치 이하로 제한한다.
- 치유 물약은 HP 80 회복. 영혼 자석은 8초간 습득 범위 확대. 기존 즉시 습득 회복 드롭도 유지한다.
- 첫 일반 사냥 처치는 장비 확정 드롭. 이후 일반 몬스터 처치별 장비 확률 25%.
- 별도로 12% 확률로 물약/자석/유물 중 하나를 드롭한다. 기존 영혼석/강화 드롭과 독립이다.
- 장비 등급 후보는 플레이어 레벨을 바탕으로 확대한다. 일부 드롭은 요구 레벨을 달성한 뒤 사용해야 한다.
- 주민은 고정 직업으로 제한하지 않는다. 모든 거래 가능한 주민이 기본 상점을 제공하고,
  교역 성향/거래 행동/누적 교역 학습치가 높은 주민은 구매가 15% 할인, 판매가 기본가의 40%를 제공한다.
  일반 주민의 판매 매입가는 기본가의 30%이다.
- 구매 대금은 주민 금화로 들어가고 판매 대금은 주민 금화에서 나온다. 주민 자금이 부족하면 판매할 수 없다.
- 거래 자체도 NPC 교역 학습치를 올린다. 장비/물약 구매, 기존 성장 구매(Y)가 금화 소비처다.

프로토타입 상점은 17종 고정 카탈로그이며 개별 아이템 재고는 무한이다(유물은 판매만 가능).
NPC가 장비 재고를 생산/운반하거나 장비를 실제 착용하는 경제는 아직 포함하지 않았다.
장비의 성능은 적용하지만 플레이어 모델/발사체를 아이템별로 교체하지는 않는다.

## 퀘스트

처음부터 확인 가능한 기본 의뢰 6개와 반복 의뢰 1개다. Q에서 완료 조건을 확인하고 보상을 직접 받는다.

| 목표 | 금화 | XP | 추가 보상 |
| --- | ---: | ---: | --- |
| 일반 몬스터 5마리 처치 | 80 | 60 | 여행자의 지팡이 |
| 바닥의 인벤토리 아이템 3개 습득 | 80 | 80 | 누빈 여행복 |
| 무기/방어구/장신구 모두 착용 | 100 | 120 | 치유 물약 |
| 서로 다른 마을 2곳 방문 | 150 | 150 | - |
| 카탈로그 아이템 구매/판매 2회 | 100 | 180 | - |
| 마을 보스 1회 처치 | 350 | 250 | 새벽의 성궁 |
| 반복: 일반 몬스터 20마리 처치 | 100 | 120 | - |

습득 의뢰는 인벤토리에 들어가는 아이템만 집계한다(즉시 소비되는 기존 영혼석 등 제외).
반복 의뢰는 누적 처치에서 수령한 20마리 단위만 차감하여 초과 진행을 보존한다.
기본 의뢰는 1회 수령하며 재접속으로 중복 지급하지 않는다.

## 마을 배치

기존 월드 크기/마을 중심/성벽/성문은 유지한다. 내부 랜드마크는 월드 시드와 마을 좌표로 결정한다.
마을마다 4개 필수 랜드마크와 최대 4개 추가 구조물을 공간 조건에 따라 배치한다.
중앙 십자 도로, 중앙 광장, 건물 앞 짧은 진입로를 유지하고 건물 간 간격/성벽 여백을 확보한다.
구조물 중심은 4~9타일의 사분면 후보에서 선택하여 중앙 통로를 막지 않는다.
같은 시드의 같은 마을은 청크 재로딩 후에도 같은 배치다. 완전히 자유로운 도시 도로 생성은 아니다.

## 저장·호환·진단

- 플레이 저장 형식: `GSE_LEVEL_ONE 3`, 내부 RPG 섹션 1.
- 인벤토리/착용/퀘스트/보스 일정/플레이어 처치 참여 피해를 저장한다.
- 기존 v1/v2 저장은 읽기 검증 후 `.before_rpg_v3.bak` 백업을 만든다.
  레벨·강화·기존 전리품은 유지하고 RPG 의뢰/가방은 새로 시작한다. 이전 클리어 상태도 반복 플레이로 전환한다.
- 월드 생성 형식 v9. 기존 마을은 `Backups/before_villages_v9` 백업 후 같은 시드로 새 배치에 이행한다.
- F9의 기존 백업 후 플레이 초기화에 새 RPG 데이터도 포함된다. 시드는 유지한다.
- 이번 작업에서 실제 사용자 저장 파일을 직접 삭제하거나 변경하지 않았다. 이행은 다음 게임 실행 시 일어난다.
- 기존 저장은 레벨 파일과 사회/금화 파일이 분리되어 있고 각각 원자 교체한다.
  거래/퀘스트 직후 두 파일을 저장하지만, 두 파일을 하나로 묶는 트랜잭션은 아니다.
  저장 도중 강제 종료/디스크 오류 시 두 파일 간 불일치 가능성은 남아 있다. 후속 개선은 통합 체크포인트/저널이다.
- 콘솔 `[BossEvent]`로 등장 위치/HP/교체를, `[Quest]`로 보상 지급을 기록한다.
  주민 거래는 기존 이벤트 로그의 `equipment_buy/equipment_sell`로 기록한다.
- 모니터 JSON에 플레이어 장비/수량/스탯, 보스 일정, 의뢰 집계를 추가했다. 패널을 열면 paused 상태로 보고한다.

## 코드 위치

- `RpgItems.h/.cpp`: 아이템 정의·설명·진행 데이터.
- `LevelOneRpg.cpp`: 착용/사용/구매/판매/의뢰/보스 일정.
- `RpgPanel.h/.cpp`: 입력·인벤토리·상점·퀘스트 UI.
- `WorldSimulationCombat.cpp`: 주민 거래 조건/가격/자금/학습.
- `LevelOneProgression.cpp`, `LevelOneResolution.cpp`: 전리품/보상/공동 처치.
- `LevelOneSave.cpp`: RPG 저장/검증/기존 저장 이행.
- `World.cpp`: 시드 기반 마을 구성.

## 사용자 빌드 후 확인 목록 (미실행)

1. 기존 저장으로 시작해 레벨/강화/시드 유지, 새 마을 배치와 백업 생성 확인.
2. Tab 열기/닫기, 키·클릭·휠·해상도 변경 시 선택/페이지/입력 잔류 확인.
3. 첫 일반 몬스터 처치 후 장비 습득, 장비 3종 착용/교체/해제, 스탯 변화 확인.
4. 물약 소모/만피 사용 방지, 자석 지속시간, 마지막 착용 장비 판매 방지 확인.
5. 주민 근처 T → 구매 → 1번 탭 X 판매, NPC/플레이어 양쪽 금화 변화 및 자금 부족 확인.
6. Q 목표 달성/보상 수령, 기본 보상 재수령 방지, 반복 의뢰 초과 처치 보존 확인.
7. 실제 진행 3분 후 보스 등장, 처치 5분 후 다른 마을 등장, 미참여 보스 5분 교체 확인.
8. Lv 10 실제 전투 시간·생존성·NPC 공동 처치 보상을 확인해 초기 수치 조정.
9. 정상 종료/재접속 후 가방·착용·금화·의뢰·보스가 이어지는지 확인.
10. 여러 마을에서 성문→중앙→건물 진입로 이동, 청크 경계/재접속 후 배치 연속성 확인.
