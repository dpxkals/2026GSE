# 마을 배치와 보행 애니메이션 정리

## 최신 변경: v14 건물 외형 다양화

같은 마을 번호가 모든 집의 모델과 지붕색을 결정하던 규칙을 없앴다. 마을마다 목조·초가·도시형·숲 주택을 혼합하며, 세 집 중 하나는 마을의 대표 양식을 선택한다. 나머지는 집 번호와 마을 번호로 순환 선택한다. 좌표와 시드에서 구한 지붕색은 모델 및 회전과 독립적이다.

각 마을에 기존 제공 에셋인 `BLD_Workshop_00_Smith` 대장간과 `BLD_Market_00_Stall` 시장 가판대를 하나씩 추가했다. 두 시설은 외형용이며 새 제작/상점 기능을 추가하지 않는다. 주민 주택 42개와 안내 NPC 주택 2개는 그대로 두고, 시설에 집 번호를 배정하지 않는다. 성당/망루·우물·묘지 역시 유지한다. 원본 모델 파일은 변경하지 않는다.

variation은 `외형 + 7 × 방향 + 28 × 지붕색`(0~195)으로 저장한다. 로더와 대체 렌더러가 각각 해석하며, 메시 캐시는 이 값을 포함해 재사용한다. `Config/AssetBindings.json`의 Cottage variants 앞 네 항목은 주택, 4번은 대장간, 5번은 가판대다. 슬롯의 의미를 유지하면서 모델 ID를 바꿀 수 있다.

v14 청크로 자동 갱신하며 원본은 `Backups/before_settlements_v14`에 보관한다. 시드와 플레이 저장, v13의 판석/흙바닥 및 중앙 길 규칙은 유지한다. 빌드·실행·화면 검증은 수행하지 않았다.

## 최신 변경: v13 마을 종류별 바닥

v12의 모든 마을 돌바닥 규칙을 대체한다. 성벽을 생성하는 왕성·수도원·광산촌은 큰 판석 바닥, 나머지 장터·농촌·숲·강변 마을은 연속된 흙바닥이다. 성벽 마을의 중앙에는 3타일 폭의 밝은 돌길을 십자형으로 깔아 네 성문과 중심을 연결한다. 중앙 길은 기존에 비워 둔 주도로 영역을 사용한다. 판석에는 3타일 간격의 옅은 이음선을 사용하며, 기존 청크 메시 배칭에 포함된다.

기존 청크는 `Backups/before_settlements_v13`에 백업한 후 갱신한다. 청크 버전과 프로파일 표기는 v13이다. 시드·플레이 데이터·건물 배치는 유지하며, 빌드와 실행 확인은 사용자에게 맡긴다.

## 후속 변경: v12 돌바닥 통일

최신 요청에 따라 모든 마을 영역은 건물 아래까지 연속된 회색 돌바닥으로 통일했다. 아래 v11 설명의 흙길·잔디·농경지 줄무늬·강변 내부 물 영역 규칙은 더 이상 적용하지 않는다. 돌바닥에는 풀/자갈처럼 보이던 작은 선 장식을 그리지 않는다. 마을 바깥 지형은 유지한다. 건물 배치와 성벽은 v11 규칙을 유지한다.

기존 청크는 다음 실행에서 원본을 `Backups/before_settlements_v12`에 보관한 뒤 v12로 갱신한다. 지형 메시 캐시는 청크 버전으로 갱신된다. 봉화 상태와 시드, 플레이 저장을 유지한다. 이번 변경도 빌드·실행하지 않았다.

## 보행

Actor가 실제 이동 거리 / 경과 시간으로 이동 속도를 전달한다. 기존 고정 1배속 Walk 대신 기준 1.8타일/초에 대한 비율로 0.5~3.5배속을 적용한다. 이 기준은 시각 튜닝값이며 모든 모델의 발 접지를 정확히 맞추는 IK 처리는 아니다. 이동 속도가 달라져도 재생 위상을 보존한다. 공격·피격·대기는 기존 시간 기준을 유지하고, 절차적 보행도 이동 거리에 따라 위상을 진행한다.

## 마을

- 일정한 6칸 격자 후보 대신 시드로 정렬한 후보에서 서로 4.5칸 이상 떨어진 위치를 선택한다. 공간이 부족하면 남은 건물을 4칸 간격으로 채운다. 같은 시드는 같은 배치를 만든다.
- 7개 마을의 기존 규모·종류·집 번호·수용 인원을 유지한다. 타원형 촌락과 직사각형 요새, 장터의 넓은 광장과 수도원의 긴 광장으로 공간을 구분한다.
- 건물은 가까운 주도로를 향하는 네 방향 중 하나를 사용한다. glTF 회전과 NPC 출입구가 같은 방향 정보를 사용한다. 원본 모델이 누락된 경우의 절차적 대체 건물은 기존 표현을 유지한다.
- 건물 주변 3×3칸을 피하는 다중 시작점 탐색으로 각 출입구에서 주도로에 연결되는 골목을 만든다. 집마다 같은 사각형 돌바닥과 일괄 가로길을 깔던 규칙은 제거했다.
- 돌은 중심 광장에 모으고 주거 주변은 흙과 풀로 구성한다. 지면의 반복 경계선을 없애고 타일별 무작위 명도 차이를 낮은 대비의 넓은 변화로 대체한다. 기반 지형은 여전히 타일 방식이다.
- 왕성·수도원·광산촌의 사방 성벽을 연결한다. 수도원·광산촌의 외곽 판정도 성벽에 맞춘다. 네 축에 출입 공간을 두고 입구 양옆과 모서리에 탑을 배치한다. 일반 촌락은 기존처럼 개방형으로 남긴다.

## 저장과 성능

청크 버전 11은 variation의 하위 7개 값을 외형, 나머지를 90도 단위 회전으로 저장한다. 기존 청크는 로드할 때 `Backups/before_settlements_v11`에 원본을 보관한 뒤 갱신하며, 기존 봉화와 점등 상태 보존 로직을 유지한다. 시드와 플레이/NPC 저장 파일을 초기화하지 않는다. 집의 위치는 바뀌며, 변경된 건물에 겹친 캐릭터는 기존 위치 복구 처리를 사용한다. 이전 실행 파일은 v11 청크를 읽지 못하므로 되돌릴 때 청크 백업도 함께 복원해야 한다.

배치와 골목 탐색은 시드당 한 번 생성해 7개 마을 계획을 재사용한다. 매 프레임 경로를 다시 생성하지 않는다. 회전은 네 방향으로 제한해 건물 메시 캐시를 재사용하고, 지면은 기존 청크 메시 배칭을 유지한다. 타일 경계선 제거는 지면 정점 수를 줄이나, 첫 마을 생성 비용과 실제 FPS는 측정하지 않았다. 프로파일 세션에는 `terrain=v11;props=settlement5`를 기록한다.

## 확인 범위

사용자 방침에 따라 빌드·게임 실행·자동 테스트·시각 결과 검증은 수행하지 않았다. 소스 변경 및 공백 오류만 점검했다. 다시 빌드해서 실행하면 로드되는 기존 청크부터 자동 갱신된다. F10만으로 월드 생성 코드 변경을 적용할 수 없다.

사용자 확인 항목: 이동/정지/속도 변경 시 보행, 일곱 마을의 배치, 각 성문 통행, 건물 출입구와 NPC 귀가, 플레이 저장 유지, 기존과 동일 시야에서의 프레임 로그.
