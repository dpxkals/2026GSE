# NPC 리깅 · 몬스터 5종 · 키프레임 애니메이션 v2

Blender 5.2 LTS / 24fps / 미터 / 2026-10-20.
요청한 모델링·리깅·애니메이션 작업만 진행했다. 게임 코드, 빌드, 저장 데이터 연결은 수행하지 않았다.

## 결과물

- `DarkAge_Rigged_Characters.blend`: NPC 공통 리그, NPC 파트 27종, 몬스터 5종, 편집 가능한 키프레임과 미리보기 장면.
- `Characters/NPC_Common_Animated.glb`: 갑옷·검 예시 NPC와 공통 스켈레톤, 애니메이션 15개.
- `Characters/MON_*_Animated.glb`: 몬스터별 메시·스켈레톤·애니메이션 13개씩.
- `NPC_Parts/*.glb`: 기존 파트 이름/인덱스를 유지한 스킨 메시 27개. 각 파일에 동일한 기준 스켈레톤이 들어 있다.
- `Data/npc_rig_contract.json`: 기존 파트 인덱스, 색상표, 조합 제한과 새 스켈레톤 연결 규격.
- `Data/skeleton_catalog.json`: 리그 ID, 본 이름, 부모 관계, 바인드 자세 좌표.
- `Data/monster_catalog.json`: 변경 가능한 몬스터 표시 이름과 고정 에셋/리그 ID.
- `Data/animation_catalog.json`: 클립 이름, 프레임 범위, 반복 여부, 이동 속도, 회전 각도, 접촉/착지 이벤트.
- `Data/rig_validation.json`: 웨이트, 클립, 관절 연결, 루프 경계 검사.
- `Data/glb_roundtrip_validation.json`, `validation_summary.json`: 재수입 검증과 전체 결과 요약.
- `Previews/`: 몬스터 목록, NPC 장착 예시, 동작 시트와 애니메이션 GIF.

기존 `../LowPoly_DarkAge_v1`의 환경 모델과 원본은 유지했다. 기존 210명 외형 레시피는 그 폴더의 JSON/CSV를 계속 사용한다. 실제 NPC ID를 연결하는 작업은 여전히 별도다.

## 제공 동작

6개 리그에 공통으로 다음 13개 클립이 있다.

| 클립 | 내용 | 반복 |
| --- | --- | --- |
| `Idle` | 호흡, 머리와 꼬리의 작은 움직임 | O |
| `Walk` | 걷기 | O |
| `Run` | 달리기 | O |
| `Move_Turn_L` / `Move_Turn_R` | 이동 중 좌우 몸 기울임·시선 선행. 방향 보간용 | O |
| `Turn_L45` / `Turn_R45` | 발을 바꿔 디디는 좌우 45도 방향 전환 | X |
| `Turn_L90` / `Turn_R90` | 좌우 90도 방향 전환 | X |
| `Jump` | 준비 동작 → 이륙 → 공중 자세 → 착지 → 회복 | X |
| `Attack_Primary` | 몬스터별 기본 공격, NPC 검/도끼 계열 공격 | X |
| `HitReact` | 충격 반응과 자세 회복 | X |
| `Death` | 쓰러짐과 마지막 자세 유지 | X |

NPC에는 `Attack_Bow`, `Attack_Cast`가 추가되어 총 15개다. 전체 80개 원본 동작이며, Blender 미리보기 시퀀스용 Action은 이 수에 포함하지 않는다.

NPC의 공통 GLB는 갑옷·검을 착용한 사용 예시다. 활 클립을 쓸 때는 검 메시를 숨기고 활 파트를 선택하고, 시전에는 지팡이 등 해당 장비를 선택한다. 활과 지팡이 파트를 추가로 로드해도 공통 리그/애니메이션을 그대로 사용한다.

키프레임은 최종 본 변환을 매 프레임 베이크한 FK 키다. 내보낸 파일은 IK 컨스트레인트나 물리 시뮬레이션을 요구하지 않는다. 원본 Action에서 키를 직접 조절할 수 있다.

## 보행과 접지

- 2족: 좌우 다리 반대 위상, 팔의 반대 스윙, 골반의 작은 상하 이동과 몸통 회전.
- 4족 걷기: 네 발의 접지 시점을 분리한 4박자.
- 하운드 달리기: 앞발과 뒷발의 위상을 어긋나게 한 갤럽, 척추 굽힘/펴짐, 꼬리의 지연 움직임.
- 멧돼지 달리기: 대각선 다리가 짝을 이루는 트로트. 하운드보다 무거운 몸통과 짧은 다리에 맞춘 동작.
- 뒷다리 피드백 반영: 과도하게 길고 수평으로 접히던 종아리를 줄이고, 무릎·발목 위치와 허벅지 볼륨을 수정했다. 멧돼지의 보폭/발 회수 높이를 낮추고, 하운드와 서로 다른 비율을 사용한다. `Previews/Hind_Before.png`, `Hind_After.png`는 수정 전후의 측면 자세 비교다.
- 하운드·멧돼지의 뒷다리는 허벅지·종아리·발목 아래 마디·발을 구분했다.
- 지지 구간의 발 높이를 고정하고, 관절 길이를 넘지 않도록 골반 높이를 보정해 키로 확정했다. 공중 구간에는 발을 들어 앞쪽으로 회수한다.
- 제자리 애니메이션이므로 미리보기 바닥 위에서는 발이 뒤로 흐른다. 실제 이동 시 JSON의 `travel_speed_mps`를 기준으로 이동량을 맞추면 지지 발의 미끄러짐을 줄일 수 있다. 3등신 NPC의 짧은 다리에 맞춰 보폭을 제한했다.

## 좌표와 적용 규칙

- Blender: +Z 위, -Y 정면, 발밑 공통 원점. glTF: +Y 위, +Z 정면.
- NPC 스켈레톤: `RIG_NPC_Common_v2`. 기존 남녀 파트 모두 같은 본 이름과 바인드 자세를 공유한다.
- 각 NPC 파트 GLB에는 기준 스켈레톤이 중복 포함된다. 게임에 적용할 때 파일별 스켈레톤을 각각 독립 재생하지 말고, 동일한 본 이름을 한 NPC 스켈레톤에 연결한다. 원본 메시와 웨이트를 공유하고 NPC마다 본 변환만 별도로 둔다.
- `JOINTS_0`, `WEIGHTS_0`, inverse-bind 행렬을 사용해야 한다. 정적 메시 로더만 사용하면 애니메이션이 보이지 않는다.
- `Walk`, `Run`, `Move_Turn_*`에는 수평 루트 이동이 없다. 이동량은 적용 작업에서 제어한다.
- `Jump`의 상하 이동은 `pelvis`에 있고 `root`는 지면 원점에 남는다. 게임의 물리 점프를 별도로 적용할 경우, 이 골반 높이를 그대로 두어 이중 상승시키지 않도록 추출/보정한다.
- `Turn_*`에는 `root` 본의 회전이 들어 있다. Blender +Z 기준 좌회전 양수, 우회전 음수다. 루트 회전의 차이를 엔티티 방향에 반영하면서 포즈의 루트 회전을 제거하거나, 엔티티 회전을 외부에서 처리하고 클립의 루트 yaw를 제거하는 방식 중 하나를 사용한다. 두 회전을 동시에 더하지 않는다.
- `Move_Turn_*`는 루트 yaw가 없는 반복 동작이다. 이동 방향 보간은 후속 작업에서 `Walk`와 좌/우 전환 동작을 블렌딩해 구현한다. 블렌드 트리나 게임의 보간 로직 자체는 포함하지 않았다.
- 무기·모자·화살통은 단단한 부착물로 웨이트를 주고, 몸통·팔·다리는 관절 경계에 혼합 웨이트를 사용했다. 긴 머리, 망토, 로브 앞뒤에는 보조 본이 있다.
- 활은 v2에서 손잡이를 손 위치에 맞게 X축으로 -0.155m 보정했다. 같은 에셋 ID를 쓰더라도 v1 정적 활과 v2 리깅 활을 섞지 않는다.

## Blender에서 확인

1. `DarkAge_Rigged_Characters.blend`를 연다. 기본 장면 `07_RIGGED_ROSTER`에서 외형을 확인한다.
2. `08_MOTION_PREVIEW`를 선택하고 Space를 누르면 걷기·달리기·방향 전환·점프·공격·피격 시퀀스를 볼 수 있다. 타임라인에 동작별 마커가 있다.
3. `09_NPC_OUTFIT_ANIMATION`에서는 긴 머리, 망토, 활, 로브, 갑옷, 등불 장착 예시를 확인한다.
4. 원본 리그를 선택하고 Dope Sheet를 Action Editor로 바꾸면 `<rig 이름>__Walk` 등의 Action을 선택할 수 있다. NLA 트랙은 내보내기 목록용으로 음소거되어 있다.
5. `01_NPC_MODULAR_RIG`에서는 기본 갑옷 조합 외의 파트를 숨겨 두었다. Outliner에서 원하는 파트를 표시하고 기존 호환 규칙에 맞춰 교체한다. 파트 인덱스는 v1과 같다.

## 이후 업데이트

설정·외형·동작은 계속 변경할 수 있다. 런타임 참조용 `asset_id`, `rig_id`, 본 이름, 파트 인덱스는 유지하고 새 항목을 뒤에 추가한다. 본의 부모 관계나 바인드 자세를 바꾸는 경우에는 새 리그 버전으로 분리한다. 이름 번역과 설정 설명은 별도 label에서 수정한다.

이번 검증은 Blender의 외형·키프레임과 GLB의 스킨/애니메이션 데이터에 대한 검사다. 실제 게임의 스키닝 셰이더, 충돌, 공격 판정, 투사체 생성, 애니메이션 상태 전환, 프레임 보간은 후속 적용 작업의 검증 대상이다. 모든 임의 장비 조합과 새 극단 자세의 관통까지 보장하지는 않는다.
