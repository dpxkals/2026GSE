## 외형 변경

- **플레이어 ‘잔불 길잡이’**: 기존 NPC 조합 대신 별도 메시로 제작했다. 새 얼굴과 비대칭 머리, 청록 여행 코트, 목도리, 어깨 망토, 주머니, 잔불 지팡이를 갖춘다. `Attack_Primary`는 지팡이 시전 키를 사용한다.
- **NPC**: 팔다리와 몸통의 단면을 조정하고, 장화·무릎·발바닥을 다시 만들었다. 망토·앞치마에는 굴곡과 안감이 있다. 기존 레시피의 체형·색상·장비 조합을 유지한다.
- **몬스터**: 허스크의 발과 등쪽 뼈, 고블린의 장비와 칼날, 오우거의 가슴석과 팔 보호대, 하운드의 목·어깨, 멧돼지의 볼과 등 털을 보강했다. 하운드·멧돼지의 v2 뒷다리 관절 위치와 키프레임을 유지한다.
- **건물 9종**: 돌담 초가, 돌출 상층 주택, ㄱ자 농가, 우진각 장옥, 강변 수상가옥, 작업 차양 대장간, 증축 여관, 후진 예배당, 원형 감시탑. 지붕 형태와 재료, 돌출부, 처마, 창·문 위치를 바꿨다. 외관용으로, 출입 가능한 실내는 없다.
- **자연물 14종**: 나무 4종, 지피식생 6종, 바위·자갈·고목 4종. 나뭇가지와 잎, 고사리 잎, 버섯에도 입체 메시를 사용했다.

## 플레이어 머리와 동작 수정

뒤통수와 관자놀이에서 두피가 머리카락을 뚫고 나오지 않도록 헤어라인을 정리했고, 턱·코와 눈의 돌출을 줄였다. 걷기·달리기는 무릎 굽힘과 뒤꿈치 접지·발끝 밀어내기를 다시 잡았고, 점프는 도약 전과 착지 후의 무릎 완충을 완만하게 조정했다.

시전은 어깨와 팔꿈치가 먼저 움직이고, 손과 지팡이가 전완을 따라가도록 키를 다시 만들었다. `Attack_Cast`의 오른손 본과 전완 본 사이 최대 각도는 기존 약 99°에서 약 5.5°로 줄었다. 플레이어 GLB의 파일명, 리그 바인드 행렬, 클립 ID 14개는 유지했다. `Previews/Player_Motion.gif`에서 보행·달리기·시전·점프를 비교할 수 있다. 검증값은 `Data/player_refinement.json`에 있다.

## 적용 작업에 전달할 정보

기존 v1/v2 파일과 게임의 `SimpleGame/Config/AssetBindings.json`은 그대로 두었다. 이 팩의 GLB 파일명은 기존 런타임 검색에서 충돌하지 않도록 별도 이름을 사용한다. Blender 원본 정면은 -Y, 위는 +Z이고, GLB는 정면 +Z, 위 +Y다.

- 플레이어 역할의 `model`: `DarkAge_Volume_v3/Characters/PLAYER_AshWayfarer`. 이 역할은 기존 `recipe` 대신 전용 모델 ID를 선택한다.
- NPC `npc_pack`은 기존 `LowPoly_DarkAge_v1`을 유지하고, `npc_rig_contract`만 `DarkAge_Volume_v3/Data/npc_rig_contract.json`으로 지정한다. 같은 파트 인덱스에 v3 GLB 경로가 연결된다.
- 몬스터는 `DarkAge_Volume_v3/Characters/MON_00_Husk_VolumeV3` 등의 파일명 ID를 사용한다. 전체 이름은 `Data/character_catalog.json`에 있다.
- 두께를 메시 자체에 넣었으므로, 기존 `default_character_thickness` 배율을 중복 적용하지 않도록 전환 시 `1.0`부터 비교한다.
- 건물·자연물의 짧은 ID는 `Data/asset_catalog.json`에 있다. 주거 7종은 `Cottage`의 외형 후보로, 예배당·원형 탑은 해당 역할 후보로 사용할 수 있다. 나무와 바위는 기존 변형 목록에 추가 가능하다. 작은 식생과 고목의 실제 배치는 게임 쪽 후속 작업이다.
- 새 환경 모델은 배치용 원점과 외관 메시만 제공한다. 실제 통행, 문 위치, 크기 보정 및 충돌은 게임에서 확인한다. 강·길·지형은 마을 미리보기 장면에만 있다.

GLB 57개의 구조를 검사했고, NPC 파트 27종의 바인드 행렬과 웨이트를 확인했다. 애니메이션 포함 GLB 7개를 Blender에 재수입해 94개 클립과 달리기 포즈 변화를 확인했다. 게임 빌드·실행과 런타임 적용은 수행하지 않았다.
