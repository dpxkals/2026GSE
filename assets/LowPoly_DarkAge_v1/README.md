# 중세 암흑시대 로우폴리 모델링 팩 v1

제작 기준: 2026-10-20 / Blender 5.2 LTS. 게임 빌드, 게임 소스 수정, 기존 저장 데이터 수정은 하지 않았다.

## 파일 열기

- `DarkAge_Modular_Library.blend`: 편집 가능한 원본. 기본 장면은 마을 디오라마.
- `Meshes/`: 이름을 유지한 개별 GLB 78개. NPC 원본 파트 27개와 환경 원본 51개.
- `Previews/`: NPC 조합, 마을, NPC 파트 목록, 환경 전체 목록 이미지.
- `Data/asset_catalog.json`: 에셋 이름, 파일 경로, 재질, 바운딩 박스, 삼각형 수.
- `Data/npc_parts.json`: 슬롯별 고정 인덱스, 조립 규격, 소켓, 색상표, 조합 제한.
- `Data/npc_presets_210.json` 및 `.csv`: NPC 210명분의 파트 및 색상 인덱스.
- `Data/validation.json`: 제작 단계 검증 수치.
- `Data/roundtrip_validation.json`: 저장된 원본 재열기 및 GLB 재수입 검증 결과.

## 미술 방향

`게임기획서_초안.txt`와 `Doc/OpenWorld_RPG_Integrated_Design.md`의 중세 암흑시대, 범람, 계승, 암울함 속 작은 희망을 기준으로 했다. 회색 석재, 낡은 목재, 채도가 낮은 의복과 초목에 따뜻한 창문·등불, 작은 새싹과 옅은 청록빛 잔흔을 배치했다. 잔흔석과 기념석의 구체적 형태는 이번 모델링의 시각 제안이며 스토리의 진실을 확정하지 않는다.

마을 분류는 현재 `SimpleGame/VillageLayout.h`, `.cpp`의 7개 마을과 마을당 30명 기준을 참고했다. 외형은 직업이나 행동 권한을 제한하지 않는다. 갑옷, 궁수복, 작업복도 자유롭게 교환하는 외형 파트다.

## Blender 장면

| 장면 | 내용 |
| --- | --- |
| `01_ASSET_LIBRARY` | 공통 원점의 원본 78종. 카테고리별 컬렉션. 원본이 겹쳐 보이는 것은 조립 좌표를 유지하기 위한 구성이다. |
| `02_NPC_SHOWCASE` | 남녀 체형, 의상, 머리, 장비를 비교하는 14명 예시 |
| `03_WORLD_SHOWCASE` | 건물과 자연물을 배치한 미술 확인용 디오라마 |
| `04_NPC_PRESETS_210` | 7행 × 30명의 조합 예시. 각 NPC 루트에 인덱스 정보 포함 |
| `05_NPC_PARTS` | NPC 파트 전체 목록. 목록용 위치는 조립 좌표와 다르다. |
| `06_ENVIRONMENT_CATALOG` | 환경 원본 51종 전체 목록 |

각 원본은 Blender Asset으로 표시되어 있다. NPC 조합 객체는 같은 메시 데이터를 링크해서 사용한다. Blender의 메시 데이터 이름은 `<asset_id>_MESH`, 내보낸 GLB 노드 이름은 `<asset_id>` 규칙을 따른다. 조합 객체 이름에는 예시 NPC ID와 원본 에셋 ID를 함께 넣었다.

## NPC 파트 조합

| 슬롯 | 인덱스 |
| --- | --- |
| `body` | 0 남성 체형 / 1 여성 체형 |
| `head` | 0 남성 얼굴 / 1 여성 얼굴 |
| `hair` | 0 짧음 / 1 긴 머리 / 2 땋은 머리 / 3 아주 짧음 |
| `torso` | 0 튜닉 / 1 갑옷 / 2 궁수 가죽옷 / 3 로브 |
| `legs` | 0 바지·장화 / 1 갑옷 다리 / 2 궁수 바지·긴 장화 |
| `back` | 0 망토 / 1 화살통 / 2 어깨 가방 / 3 앞치마 |
| `hand` | 0 검 / 1 활 / 2 지팡이 / 3 도끼 / 4 등불 |
| `headwear` | 0 후드 / 1 투구 / 2 천 모자 |

선택 파트의 `-1`은 미장착이다. `body`, `head`, `torso`, `legs`는 필수다. 남녀는 같은 접합 규격을 공유하며 머리 길이, 의복, 장비를 성별로 제한하지 않는다.

명목 키 1.8m, 머리 높이 0.6m인 3등신이다. 신발 바닥 Z=0, 다리 영역 약 0~0.6m, 몸통 약 0.6~1.2m, 머리 1.2~1.8m. 머리카락·모자·장비는 키를 조금 넘을 수 있다. 모델은 정적 A 자세다.

모든 NPC GLB는 발밑의 동일 원점을 유지한다. 각 파트를 같은 위치·회전·배율로 겹쳐 놓으면 조립된다. 개별 머리나 의상을 자신의 바운딩 박스 중심으로 재정렬하지 말 것. 손 장비 역시 이미 손 위치에 맞춰져 있으므로 처음 조립할 때 소켓 좌표를 한 번 더 더하지 않는다. 소켓은 추후 리깅·장비 부착 기준점이다.

### 겹침 방지 규칙

- 후드 또는 투구(`headwear=0/1`)에는 `hair=-1`을 사용한다.
- 화살통(`back=1`)에는 긴 머리와 땋은 머리(`hair=1/2`)를 조합하지 않는다.
- 로브(`torso=3`)에는 어깨 가방과 앞치마(`back=2/3`)를 조합하지 않는다.

이 규칙은 JSON에도 들어 있다. 제공한 210개 프리셋은 규칙을 만족한다. 모든 임의 조합과 향후 애니메이션에서의 관통까지 보장하는 규격은 아니므로, 새 자세나 새 파트를 추가하면 별도로 외형을 확인한다.

### 색상으로 개체 구분

피부 4종 × 머리색 5종 × 의복색 7종의 재질 색상표를 제공한다. 인스턴스는 `MAT_Skin`, `MAT_Hair`, `MAT_Cloth` 슬롯을 각 `PAL_*` 재질로 교체한다. 기본 개별 GLB는 공통 기본색을 사용한다. NPC 프리셋의 색상 인덱스는 적용 작업에서 재질 교체 또는 셰이더 색상 파라미터로 반영해야 한다. JSON의 색상 값은 선형 RGB다.

건물 지붕용 7색도 제공하지만 별도 메시를 복제하지 않았다. `MAT_Roof`를 교체하면 된다. 초가와 산림 오두막의 지붕은 각각 `MAT_Thatch`, `MAT_Leaf`로 미술적 차이를 유지했다.

### NPC별 정보와 실제 ID 연결

210개 `NPC_PRESET_001`~`210`은 실제 저장 데이터와 아직 연결되지 않은 외형 레시피다. `town_index`, `local_index`, `parts`, `palette`가 있고 `runtime_npc_id`는 `null`이다. 저장된 NPC의 실제 ID를 후속 적용 작업에서 연결해야 한다. 인덱스 순서를 실제 NPC ID로 간주하면 안 된다.

Blender의 각 NPC Empty에도 `recipe_id`, `part_indices_json`, `palette_indices_json`, `runtime_npc_id=UNBOUND`를 기록했다. 각 자식 메시에는 `source_asset`, `part_slot`, `part_index`가 있다. 인덱스는 v1에서 순서를 바꾸지 않고 새 파트를 뒤에 추가하는 방식으로 확장한다.

## 환경 구성

- 건물 8종: 목골조 주택, 초가, 2층 주택, 대장간, 산림 오두막, 수도원 예배당, 내성, 시장 노점.
- 건축 모듈 8종: 2m 성벽, 열린 성문, 망루, 폐허 벽, 계단, 다리, 선착장, 2m 목책.
- 수목 6종: 참나무, 침엽수, 고사목, 버드나무, 어린 나무, 그루터기.
- 지피 식물 8종: 생풀, 마른 풀, 고사리, 갈대, 들꽃, 관목, 보리, 이끼.
- 바위 5종: 작은 돌, 큰 바위, 판석, 철광석, 절벽.
- 지형 타일 4종: 흙, 판석길, 밭, 얕은 물. 기본 2m 규격.
- 소품 12종: 우물, 상자, 통, 손수레, 묘비, 기념석, 등불 기둥, 모닥불, 표지판, 벤치, 보급품, 범람 흔적석.

풀과 나뭇잎도 실제 저폴리곤 입체/면 메시로 만들었으며 알파 텍스처를 요구하지 않는다. 건물은 독립된 완성 에셋이고 성벽·다리·목책 등은 별도 배치 모듈이다. 문과 창은 외관용이며 건물 내부와 개폐 구조는 포함하지 않는다. 선착장 기둥은 수면 아래로 내려가도록 원점보다 아래까지 뻗어 있다.

## 내보내기 규격과 다음 작업

- `.blend`: 미터, +Z 위, -Y 정면.
- `.glb`: 표준 glTF 좌표, +Y 위, +Z 정면. Blender `(x,y,z)` → glTF `(x,z,-y)`.
- 원본의 위치·회전·배율은 항등 변환이며 삼각형으로 확정했다. 정점 색/텍스처 대신 이름 있는 단색 PBR 재질을 사용한다.
- 모든 메시 원본의 합계는 15,458 triangles, 단일 메시 최대 728 triangles다. 이는 210명 전체를 배치했을 때의 렌더링 삼각형 수가 아니다.
- 하나의 메시가 여러 재질 primitive로 나뉠 수 있다. 메시 공유가 draw call 하나를 의미하지는 않는다. 재질 묶기·GPU 인스턴싱은 적용 작업에서 결정한다.
- 원본 GLB에는 미리보기용 바닥, 글자, 카메라, 조명이 들어 있지 않다. 발광 재질은 들어 있지만 실제 광원은 후속 엔진에서 설정한다.
- 리깅, 스킨 웨이트, 애니메이션, 충돌 메시, UV 텍스처 아틀라스, LOD, 게임 로더는 이번 범위에 포함하지 않았다.
- 후속 작업은 이름·슬롯 인덱스 계약을 기준으로 실제 NPC 데이터 연결, 재질 색상 적용, 좌표 변환, 장비/애니메이션 연결을 진행하면 된다.

제작 과정의 확인: 원본 저장, 4종 미리보기 렌더 확인, 210개 조합의 고유성과 규칙 검사, 메시 공유 검사, GLB 재수입 및 이름/범위/삼각형 검사. 게임에서의 적용·성능·동작 검증은 수행하지 않았다.
