레벨 1: 잿빛 들판 — 파밍 입문
작성일: 2026-09-14

이번 레벨의 목적
이동하며 자동 원거리 공격의 사거리를 익히고, 적이 떨어뜨리는 아이템을
모아 레벨과 무기를 성장시킨 뒤 보스를 처치한다.
기존 쿼터뷰, 청크 스트리밍, 한글 NPC 대화, HDR 후처리를 그대로 사용한다.
월드 전체에 고정된 끝을 만들지 않고 첫 전투 단계로 레벨 1을 구성했다.

진행 순서
1. 시작 거점의 이안과 세라에게 F로 말을 걸어 파밍 안내를 듣는다.
2. 초록색 안전 원 밖으로 이동한다. 원 안에서는 적에게 피해를 받지 않고
   초당 체력 5를 회복하며, 자동 공격과 신규 적 생성은 잠시 멈춘다.
3. 적이 사거리 안으로 들어오면 자동으로 조준하고 발사한다.
4. 파란 영혼석과 주황 강화석을 주우며 성장한다.
5. 일반 적 24마리를 처치하면 다음 유효한 생성 위치에 보스가 등장한다.
6. 보스의 붉은 원과 방사형 탄환을 피하면서 공격한다.
7. 보스 처치 시 레벨 1 완료 메시지와 보상 드랍이 나온다.
   이후 신규 적 생성과 전투는 멈추며, 남은 아이템 수집과 탐험은 가능하다.

조작
WASD / 방향키: 이동.
공격: 별도 입력 없이 자동.
R: 사거리 원 표시 켜기/끄기.
P: 일시정지/재개.
F: 가까운 NPC와 대화.
대화 중 F / Enter / Space: 다음 대사.
대화 중 Esc: 대화 닫기. 평상시 Esc: 저장 후 종료.
E: 가까운 봉화 점화.
Home: 거점 안 또는 레벨 완료 후 시작 위치로 복귀. 전투 중 즉시 귀환은 제한.
휠 / +/-: 확대·축소.
F1: 청크 경계. F2~F5: 후처리 전환. F6: 후처리 기본값.
[ / ]: 노출 조절.

대화, P 일시정지, 다른 프로그램으로 포커스 이동 시 이동·공격·적 행동이 멈춘다.
NPC 대화의 경우 대사와 버튼 안내도 한글이다.

자동 공격
- 기본 사거리: 월드 좌표 6타일. R로 경계를 볼 수 있다.
- 범위 안에서 장애물에 가리지 않은 가장 가까운 적을 선택한다.
- 발사 시점의 적 방향을 향해 직선으로 날아가며, 유도탄은 아니다.
- 발사체는 최대 6타일 이동 후 사라진다. 벽/물/지형 장애물에 닿아도 사라진다.
- 공격 판정은 이동을 작은 구간으로 나눠 처리하여 빠른 탄환의 통과를 줄인다.
- 일반 발사체는 한 적에게 한 번만 피해를 준다.
- 조준 중인 적 발밑에는 표식을 표시한다.

성장 수치 — 초기 밸런스, 플레이 결과에 따라 조정 예정
플레이어 레벨 L, 무기 강화 W 기준:
- 시작 레벨 1, 체력 100, 무기 +0.
- 공격력 = 12 + (L - 1) x 2.5 + W x 4.
- 발사 간격 = max(0.24, 0.85 x 0.91^(L - 1) x 0.96^W)초.
- 최대 체력 = 100 + (L - 1) x 15.
- 다음 레벨 필요 경험치 = 24 + (L - 1) x 16.
- 레벨업 시 현재 체력 +25, 증가한 최대 체력을 넘지 않는다.
- 이동 속도 = 4.5 + min(0.9, (L - 1) x 0.06)타일/초.
- 기본 자동 습득 범위 = min(4.0, 2.2 + (L - 1) x 0.15)타일.
- 현재 시제품의 상한: 레벨 30, 무기 +20. 상한에서 경험치는 더 쌓지 않는다.
- 피격 후 0.65초간 추가 피해를 막고 캐릭터를 깜빡이게 표시한다.

드랍과 자동 습득
파랑 / 영혼석:
  일반 적 처치 경험치 +4 외에, 경험치 +8인 영혼석을 반드시 드랍한다.
주황 / 강화석:
  일반 적 4마리마다 무기 +1 강화석을 반드시 드랍한다.
빨강 / 회복약:
  체력 +30. 6마리마다 보장하며 다른 처치에서도 12% 확률로 추가 발생한다.
  체력이 가득 찼다면 소비하지 않고 바닥에 남긴다.
청록 / 자석:
  9마리마다 보장한다. 습득 후 8초간 12타일 범위 아이템을 끌어온다.
  재습득하면 남은 시간이 8초로 갱신된다.

모든 아이템은 가까이 가면 플레이어 쪽으로 이동하며 자동 습득된다.
자석은 이 범위와 이동 속도를 크게 늘린다.
아이템은 습득 중 지형을 통과할 수 있다. 공격 발사체와 구분되는 연출이다.
드랍을 시간 만료나 거리만으로 삭제하지 않는다. 습득한 아이템은 제거하고
그 효과와 남아 있는 아이템 목록을 같은 전투 저장 파일에 기록한다.

적과 보스
잿빛 망자: 체력 34, 이동 1.8타일/초, 근접 피해 8.
사냥개: 체력 24, 이동 2.7타일/초, 근접 피해 10.
일반 적은 파밍이 진행되면 생성 간격이 짧아지고 근처 활성 수가 4에서 최대 12로 늘어난다.
생성 위치는 플레이어와 경로로 연결된 타일 중 6.5~9타일 떨어진 곳에서 고른다.
적이 겹친 위치나 안전 거점 내부에는 생성하지 않는다.

보스 '잿빛 파수꾼':
- 일반 적 24마리 처치 후, 거점 밖의 유효한 위치에 1명 생성.
- 체력 650. 보스전이 시작되면 일반 적의 신규 생성은 멈춘다.
- 플레이어 위치를 찍고 1.25초 동안 붉은 원으로 공격을 예고한다.
- 예고가 끝나면 반경 2.3타일 공격, 이후 8방향 탄환을 발사한다.
- 기본 바닥 공격 피해 24, 방사형 탄환 피해 12, 접촉 피해 14.
- 체력 50% 이하에서 이동 속도와 공격 빈도가 증가하고 바닥 피해가 32로 증가한다.
- 화면 밖에 있으면 BOSS 표시로 방향을 안내한다.
- 처치 보상: 직접 경험치 +100, 영혼석 +80, 무기 +3, 회복 +60, 자석.
- 레벨 완료 후 남아 있는 일반 적은 전투 갱신을 멈춘다.

맵 생성과 갇힘 방지
- 새 월드의 첫 실행에 무작위 시드를 뽑고 world.meta에 저장한다.
- 길은 월드 좌표의 완만한 곡선과 노이즈로 만든다.
  청크 경계 도로와 청크별 십자 통로는 새 생성기에서 제거했다.
- 숲·호수는 위치와 크기가 다른 장애물 군집으로 배치한다.
  군집 둘레의 이동 가능한 풀밭을 남겨 우회할 수 있게 한다.
  이 여유 공간을 모두 흙길로 칠하지 않는다.
- 큰 강, 대륙, 마을 간 도로망을 완성한 단계는 아니다.
- 기존 청크(v2)는 지형과 봉화 상태를 그대로 불러온다.
  새로 생성되는 청크에 자연 지형(v3)을 적용한다. 기존 지역을 자동 재생성하지 않는다.
- NPC는 시작 공터에 배치한다. 적은 플레이어에서 도달 가능한 타일에 생성한다.
- 아직 불러오지 않은 청크는 이동을 막는다.

새 지형을 처음부터 볼 때
실행 인수에 --natural-world 를 지정한다.
Visual Studio: 프로젝트 속성 → 디버깅 → 명령 인수에 입력.
이 옵션은 SaveData/Level01_natural_v2 라는 별도 슬롯을 사용한다.
같은 옵션으로 다시 실행하면 그 슬롯의 진행을 이어간다.
옵션 없이 실행하면 기존 Level01_v1 슬롯으로 돌아간다.
어느 슬롯도 삭제하거나 덮어서 초기화하지 않는다.
별도 슬롯이 이미 있다면 재사용하므로 매번 새 시드를 만드는 옵션은 아니다.

사망과 영혼 NPC
- 체력이 0이 되면 사망 지점에 영혼 NPC가 정확히 한 명 태어난다.
- 플레이어는 거점에서 부활하고 레벨·강화·아이템·보스 진행은 유지한다.
- 사망 ID, 사망 순번, 위치, 당시 레벨과 무기, 삶의 기록을 저장한다.
- 기록 범위는 직전 부활 이후의 한 삶이다. 플레이 시간, 이동 거리, 발사 횟수,
  처치 수, 받은 피해, 영혼석 수집, 회복약 사용, 대화 횟수를 담는다.
- 이 기록으로 탐험·관계·수집·전투 성향을 표현한다.
- 희망·결의·두려움은 회복/전투 경험을 바탕으로 한 게임 캐릭터의 감정 잔향이다.
  실제 플레이어의 심리나 알 수 없는 동기를 확정하지 않는다.
- NPC는 '잔향 N'으로 표시된다. 화면의 SOUL 표식을 따라 돌아가 F로 대화한다.
- 한글 대사는 기록과 재방문 여부를 반영하는 로컬 규칙 기반이다.
  외부 AI 서비스 연동, 자유 입력 대화와 자율 NPC 생활 시뮬레이션은 아직 없다.
- 영혼은 길을 막지 않으며 시간이 지나거나 청크를 벗어나도 삭제되지 않는다.
  겹친 영혼은 만난 횟수가 적은 쪽을 우선하여 여러 영혼과 차례로 대화할 수 있다.
- 사망에 따른 생성·삶 기록 초기화·부활은 하나의 전투 체크포인트에 함께 저장한다.
- 구버전 전투 저장은 읽어서 이어가고 첫 변환 전에 level_one.dat.v1.bak을 보관한다.
  과거 '전투 불능 후퇴'에는 삶 기록이 없으므로 영혼을 소급 생성하지 않는다.

새 저장 위치:
실행 파일 폴더 / SaveData / Level01_v1 /
- world.meta: 세계 시드와 생성 버전.
- 좌표.chunk: 지형 생성 버전, 지형과 봉화 상태.
- residents_v1.dat: 거점 NPC 만남 기록.
- level_one.dat(v2): 플레이어·전투 진행, 적·아이템, 현재 삶, 영혼 NPC와 만남, 난수 상태.

기존 SaveData/World_v1_20260908 폴더는 수정하거나 삭제하지 않는다.
기존 프로토타입과 레벨 1의 세이브는 자동으로 변환하거나 합치지 않는다.
정상 종료, 사망/처치/아이템 습득/보스 등장, 영혼 대화, 플레이 중 5초마다 저장한다.
게임이 강제 종료되면 마지막 저장 이후 이동·체력 등의 변화는 유실될 수 있다.
발사체와 공격 예고는 일시적 상태이며 재접속 시 초기화한다.
저장 실패나 형식 오류는 기존 파일을 보존하고 진행을 멈춰 알린다.
자동 백업, 멀티 인스턴스 동시 저장과 장기간의 대규모 데이터 최적화는 후속 과제다.

가림 처리와 메시 캐싱
- 캐릭터보다 앞에 그려지는 나무·폐허·돌·봉화 기단의 삼각형이
  머리 또는 몸통을 덮으면 불투명도를 약 25%까지 부드럽게 낮춘다.
- 벗어나면 다시 불투명해진다. 화면상 가림만 바꾸며 충돌은 유지한다.
- 지형은 청크별 로컬 메시, 구조물은 종류/외형별 메시를 최초 한 번 생성한다.
- 적의 몸체, 드랍 아이템, 영혼도 상태/종류별 메시를 재사용한다.
- VAO/VBO와 정점 데이터를 캐시하고 GPU에는 GL_STATIC_DRAW로 올린다.
  재사용 시 위치·배율·불투명도만 셰이더 uniform으로 바꾼다.
- 청크가 메모리에서 해제되면 해당 지형 GPU 캐시도 해제한다.
  다시 불러온 청크는 메시를 재구축한다. 캐시는 영구 세이브가 아니다.
- 물결·불꽃·플레이어 애니메이션·체력 바·탄환 등 동적 표현은 별도로 갱신한다.
- 실제 프레임 시간과 드로콜 개선 여부는 아직 측정하지 않았다.
- 상단 MESH CACHE 숫자는 보관 중인 메시 수다. GPU 할당 실패 시 콘솔에 알리고
  보관 중인 CPU 정점을 사용한다.

셰이더 파일
- Shaders/Scene.vs, Scene.fs: 월드/UI, HDR 색 처리와 캐시 메시 변환.
- Shaders/Fullscreen.vs: 후처리 전체 화면 공통 정점 셰이더.
- Shaders/Prefilter.fs, Blur.fs, Composite.fs: 블룸 추출, 블러, 최종 합성.
- 기존 SolidRect.vs/.fs는 레거시 렌더러용으로 유지한다.
- SceneRenderer와 PostProcessor의 코드 내 GLSL 문자열은 제거했다.
- 빌드 시 .vs/.fs를 실행 파일 옆 Shaders 폴더에 자동 복사한다.
  셰이더만 수정했을 때도 빌드를 한 번 거쳐 배포 파일을 갱신한다.
- 실행은 작업 디렉터리가 아니라 EXE 옆 Shaders 폴더에서 파일을 읽는다.
  배포할 때 EXE와 이 폴더를 함께 전달해야 한다.
- Scene 셰이더 누락/오류는 시작 실패, 후처리 셰이더 오류는 기본 렌더링 전환.
  자세한 파일 경로와 컴파일/링크 로그는 콘솔에 남긴다.

파일 구조
LevelOne.h/.cpp: 성장 수치, 자동 조준, 적 행동, 탄환, 드랍, 보스 진행.
LevelOneSave.cpp: 전투 데이터 읽기, 유효성 검사와 파일 교체 기반 저장.
LevelOneView.h/.cpp: 적·아이템·탄환·공격 예고·전투 HUD 표현.
SoulNpc.cpp: 삶의 전송, 영혼 NPC와 기록 기반 한글 대화.
SceneMesh.cpp: 정적 GPU 메시 캐시와 가림 검사.
ShaderProgram.h/.cpp: 실행 파일 기준 셰이더 파일 로딩.
World.h/.cpp: 무작위 시드와 청크와 독립적인 자연 지형 생성.
SimpleGame.cpp: 기존 입력, 월드 렌더링, NPC 대화와 전투 시스템 연결.

사용자가 확인할 항목
이번 변경은 코드 작성 단계이며 빌드·테스트·실행 확인은 진행하지 않았다.
기본 창 크기 1280x800, Visual Studio Debug/x64 구성을 기준으로 확인한다.
1. 처음 실행 시 NPC, 안전 거점, 체력/경험치 HUD와 파밍 안내가 보이는지.
2. 원 밖에서 적이 나타나며, 사거리 밖/벽 뒤에서는 발사하지 않는지.
3. 피격과 발사체 피해가 적용되고 경험치가 레벨업으로 이어지는지.
4. 강화석·회복약·영혼석·자석을 습득했을 때 표시 수치가 맞게 변하는지.
5. 체력이 가득 차면 물약이 남고, 체력을 잃은 뒤에는 습득되는지.
6. --natural-world에서 청크 경계가 도로로 드러나지 않고, 음수 좌표에서도 길과 풀밭이 이어지는지.
7. 일반 적 24마리 처치 후 보스가 등장하고, 붉은 원 공격과 탄환을 피할 수 있는지.
8. 보스 체력 50% 이하에서 공격이 빨라지고, 처치하면 완료/보상이 나오는지.
9. 사망마다 영혼이 한 명 생기고 부활 후 F로 만날 수 있는지. 반복 사망/재접속에서 중복되지 않는지.
10. 재실행 후 플레이어 위치·성장·보스 체력·드랍 상태가 이어지는지.
11. P, 대화, 다른 창 전환 중 체력이나 전투 상황이 진행되지 않는지.
12. 한글 대화와 기존 HDR 효과 조작이 계속 동작하는지.
13. 영혼 대화 중 전투가 멈추고, 다음 삶의 기록이 이전 영혼의 기록을 바꾸지 않는지.
14. 나무/폐허 뒤에서 반투명해지고 앞이나 옆에서는 원상복귀하는지.
15. 확대·축소/창 크기 변경 후 캐시된 지형·구조물·적·아이템 크기와 위치가 맞는지.
16. 작업 디렉터리를 바꿔도 EXE 옆 Shaders에서 읽는지.
17. 재방문한 봉화의 점화 상태, 두 저장 슬롯의 진행이 각각 유지되는지.
